#### MockTTSEngine Features

**Interface Compliance**:
```typescript
export class MockTTSEngine implements VoiceEngine {
  name = 'Mock TTS (Development)';
  supportsStreaming = false;
  
  async *synthesizeStream(text: string): AsyncIterable<VoiceChunk>
```

- **Logging**: Clear console messages for debugging
- **Duration clamping**: 1-5 second range for reasonable testing

## 🔍 Key Learnings

### 1. Environment Variable Confusion

**Issue**: Expo requires `EXPO_PUBLIC_*` prefix for web builds, but this wasn't obvious from error messages.

**Resolution**: 
- Created clear documentation explaining the prefix requirement
- Automated the prefixing in sync script
- Added debug logging showing all env vars on startup

### 2. Sync Script Robustness

**Challenges**:
- Inline comments in `.dev.vars` (e.g., `MODE=mock # comment`)
- Quote handling (single, double, none)
- Whitespace variations
- Missing fields

**Solutions**:
- Strip inline comments: `${VAR%%#*}`
- Remove quotes: Multiple substitutions
- Trim whitespace: `xargs` command
- Safe defaults with clear warnings

### 3. Mock Mode Design

**Key Decisions**:
- Mock mode should be DEFAULT (safety first)
- Simulation timing should be realistic (not instant)
- Console logging should be clear and helpful
- No network calls AT ALL (not even healthchecks)

**Implementation**:
- Word-based duration calculation
- Proper state management (isPlaying toggle)
- Clear emoji indicators (🎭 vs 📡)
- Helpful console messages for debugging
